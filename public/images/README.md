# Logo Asset

Place your HanapBuh.AI logo file here as **logo.png**.

- **Recommended format:** PNG with transparent background
- **Recommended size:** At least 256x256px for best quality across all uses
- **Filename:** Must be exactly `logo.png`

The logo will appear in:
- Navbar (public and authenticated layouts)
- Footer
- Login, Register, and Email Verification pages
- Admin Panel sidebar
- Favicon (browser tab)
