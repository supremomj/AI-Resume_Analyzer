# Scripts

This folder contains utility scripts and test files.

## Contents

- **Test Scripts**: PHP files for testing API connections and functionality
- **Batch Files**: Windows batch scripts for automation
- **Check Scripts**: Configuration verification scripts

## Usage

Run scripts from the project root directory:

```bash
php scripts/test_ai_connection.php
scripts/start_flask_api.bat
```

## Important Notes

- Test scripts may require database connection
- Batch files assume Flask API is in the default location
- Always check script paths before running
